# Задачник SQL

Задачи на SQL с проверкой прямо на странице: запросы выполняются в браузере, в учебной базе
SQLite. Ничего устанавливать не нужно, сервер не нужен, прогресс нигде не сохраняется.

## Как пользоваться

1. Прочитай условие и открой «Схему базы» — там таблицы и столбцы.
2. Пиши запрос в поле и жми «Выполнить» (или Ctrl/⌘ + Enter), чтобы посмотреть результат.
3. Когда результат похож на правду — «Проверить». Проверка запускает твой запрос на свежей копии
   базы и сравнивает результат с эталоном: число столбцов и набор строк. Имена столбцов и порядок
   строк (если в условии не сказано обратное) не важны.
4. «Подсказку» открывай, если застрял. «Эталонный запрос» — только после своей попытки:
   правильных запросов обычно несколько.

Испортить ничего нельзя: «Сбросить базу» возвращает исходные данные, а каждая проверка и так
начинается с чистой базы.

Если запрос завис (например, рекурсия без условия выхода или JOIN без условия), через 5 секунд
он будет остановлен, а база пересоздана с исходными данными — страницу обновлять не нужно.

## SQLite и PostgreSQL: что отличается

TaskFlow работает на PostgreSQL, а здесь — SQLite. Базовый SQL одинаковый, но есть отличия:

- **Типы.** В SQLite нет `BOOLEAN` (вместо него `0`/`1`), нет отдельных типов даты и времени,
  типы столбцов нестрогие. В PostgreSQL — `boolean`, `timestamp with time zone`, строгие типы.
- **Даты** здесь хранятся текстом в ISO: `'2026-03-14T09:30:00Z'`. Сравнивать их можно как
  строки, части доставать через `substr()` или `strftime('%Y', created_at)`. В PostgreSQL —
  `EXTRACT(YEAR FROM created_at)`, `date_trunc`, `NOW()`.
- **`ILIKE` нет.** В SQLite `LIKE` сам не различает регистр, но только для латиницы:
  `'Ivan' LIKE 'ivan'` — истина, `'Петров' LIKE 'петров'` — ложь. `lower()` и `upper()` в SQLite
  тоже меняют только латиницу. В PostgreSQL `LIKE` различает регистр, а для поиска без учёта
  регистра есть `ILIKE` и `lower()`, которые понимают кириллицу.
- **Склейка строк** — `||` в обеих: `first_name || ' ' || last_name`. Функция `concat()` тоже
  есть в обеих (в SQLite — с версии 3.44, здесь 3.49).
- **`LIMIT`/`OFFSET`** — одинаково. Стандартное `FETCH FIRST n ROWS ONLY` SQLite не понимает.
- **`RIGHT JOIN` и `FULL JOIN`** есть в SQLite только с версии 3.39 (здесь 3.49 — работают).
- **Деление целых** в обеих СУБД целочисленное: `7 / 2 = 3`. Нужна дробь — `7 * 1.0 / 2`.
